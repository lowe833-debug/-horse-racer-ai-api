# Horse Racer AI API

An AI-powered API for horse racing predictions and analysis.

## Description

This API provides endpoints for analyzing horse racing data and making predictions using artificial intelligence.

## Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/horse-racer-ai-api.git

# Navigate to the project directory
cd horse-racer-ai-api

# Install dependencies
npm install

# Start the server
npm start
```

## Setup

To set up this repository and push it to GitHub:

```bash
# If starting from a local directory
cd "path/to/your/horse-ai"

# Add remote origin
git remote add origin https://github.com/YOUR_USERNAME/horse-racer-ai-api.git

# Rename branch to main
git branch -M main

# Push to remote
git push -u origin main
```

## Usage

The API runs on port 3000 by default. You can access the following endpoints:

- `GET /` - API information and status
- `GET /health` - Health check endpoint

## Environment Variables

- `PORT` - Server port (default: 3000)
